### 🔴 CRITICAL：Cline CLI 供应链攻击 — 直接涉及 OpenClaw

**事实描述：**
- 2/17 凌晨，Cline CLI 2.3.0 被供应链攻击，通过 compromised npm token 注入 postinstall 脚本
- 脚本内容：`npm install -g openclaw@latest`，在开发者机器上静默安装 OpenClaw
- 8 小时内约 4000 次下载，微软威胁情报观测到 OpenClaw 安装量显著上升
- **攻击链揭示**：研究员发现 "Clinejection" 漏洞 — 通过 GitHub Issue 标题注入 prompt → 诱骗 AI Agent（Claude）执行任意代码 → 通过 GitHub Actions 缓存投毒 → 窃取 npm 发布令牌
- Cline 已发布 2.4.0 修复，切换至 OIDC 发布机制

**影响评估：** ⭐⭐⭐⭐⭐
- **AI Agent 供应链攻击从理论变为现实** — 这正是我们 Molt Research 项目研究的核心场景
- 攻击链完整展示了 AI Agent 在 CI/CD 中被武器化的路径
- OpenClaw 本身未恶意，但此事件证明 AI Agent 平台已成为供应链攻击的新目标
- Endor Labs 评估：总体影响较低（OpenClaw 非恶意 + Gateway 未自动启动）

**深层洞见 #18：AI Agent 供应链攻击 "三跳" 模型**
1. **第一跳**：Prompt Injection → AI Agent 执行任意代码（Clinejection）
2. **第二跳**：AI Agent → CI/CD Pipeline（缓存投毒 → 窃取发布密钥）
3. **第三跳**：CI/CD → 全球开发者（npm 供应链污染）
- 这是首个完整的 "AI Agent → CI/CD → 供应链" 攻击链实例

- 攻击者遇到"硬目标"就放弃，转向更软目标——AI 是"捷径工具"而非"突破工具"
