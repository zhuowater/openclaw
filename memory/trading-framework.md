## 〇、道：交易的终极哲学

### 从"预测"转向"应对"

**顶级交易者不是预言家，是猎人。**

- **承认无知**：市场短期不可预测。承认这一点不是软弱，是认知上的准确（Gödel 不完备定理的交易版）
- **概率思维**：每笔交易只是概率分布中的一个样本。单次胜负无意义，只有在**正向预期系统下重复执行**才有意义
- **反脆弱性**（Taleb）：构建"错的时候损失有限，对的时候获利惊人"的结构。不是防御，是从混乱中获益

> 不去预测风从哪里来，而是确保风来的时候自己站在正确的位置。

### 非对称性：唯一值得追寻的东西

所有策略的本质都是寻找**风险收益比极不平等**的切入点：

| 策略维度 | 表现 | 核心逻辑 |
|----------|------|----------|
| **趋势跟踪** | 截断亏损，让利润奔跑 | 不猜顶底，只吃鱼身最肥的部分 |
| **均值回归** | 寻找过度偏离的极端情绪 | 利用恐惧/贪婪制造的"定价错误" |
| **波动率交易** | 低波动埋伏，高波动获利 | 波动率的周期性比价格更可靠 |

**伊朗 NO 的反面教材**：$0.94 买 NO = 赔率 1:16。赢了赚 $0.06，输了亏 $0.94。这是**完美的负非对称性** — 恰好是应该避免的结构。

### 三大支柱 (Holy Trinity)

缺一不可：

**1. 心法 (Mindset)**
- 情绪的绝对中性：亏损时无愤怒，盈利时无狂喜
- 当你能机械执行计划而心跳不加速 → 你已经赢了 90% 的人
- **交易的最高境界是极其无聊的**

**2. 资金管理 (Money Management)**
- 生存是第一优先级 — 永远不因一两次极端意外被迫下桌
- 单笔风险 ≤2% 总资产（凯利公式的保守版）
- **你能承受连输 10 次还能继续玩，才有资格谈策略**

**3. 方法论 (Methodology)**
- 必须有经过验证的、具有统计学优势的信号系统
- 不是"我觉得会涨" → 是"这个模式历史上 X% 概率盈利，平均盈亏比 Y:Z"
- 本框架的六个分析层就是方法论的骨架

### 交易者的"禅"

> 交易不是为了寻找刺激，而是为了赚钱。

当你发现自己只是在机械地执行计划，没有任何心跳加速的感觉时，那就是步入"顶级"行列的标志。

**自检信号**：
- 🟢 下单时像填表格一样平静 → 正确状态
- 🔴 下单时兴奋/紧张/急切 → 停下来，你在赌博不是在交易
- 🔴 亏损后急于"赚回来" → 停下来，这是 tilt（情绪失控）
- 🔴 连续盈利后加大仓位 → 停下来，这是过度自信

## 一、认识论层：我凭什么比市场更聪明？

**核心原理**: Shannon 信息论 — 信息有物理成本，免费午餐不存在

### 信息优势三问（每笔交易前必答）

| 优势类型 | 问题 | 伊朗教训 |
|----------|------|----------|
| **时间差** | 我比市场更早知道某事吗？ | ❌ 没有，新闻全球同步 |
| **解读差** | 同样信息我理解得更深吗？ | ❌ 没有，甚至没读完市场描述 |
| **结构差** | 我看到了市场看不到的关联吗？ | ❌ 没有，纯直觉下注 |

**铁律: 三种优势都没有 → 不交易。**

### 信息验证清单
- [ ] 读完市场的**完整描述**（不只是标题）
- [ ] 搜索 X/新闻获取最新情报
- [ ] 检查市场的 resolution source（谁判定结果）
- [ ] 写下交易假设：「我在赌 _____ 会发生，因为 _____。如果 _____ 发生我就错了。」

## 二、拓扑层：风险不可消灭，只能分配

**核心原理**: 毛球定理 — 奇点必然存在，关键是选择在哪里失败

### 杠铃策略

```
[80% 确定性仓位] ←————————→ [20% 彩票仓位]
  低风险、高概率               高风险、高赔率 (3x+)
  Fed不变、明确事件             regime change、黑天鹅
  
         ❌ 禁区：中间地带 ❌
     看似安全但赔率差的 NO token
     (>$0.85 的 NO = 赔率 1:6+)
```

### 仓位管理
- **单主题 ≤15% 总资产**（伊朗踩了 31%）
- **同方向不重复建仓** — 一个论点只下一注
- **总持仓 ≤60% 总资产** — 保留 40% 现金应对机会

### 奇点预算
接受每 10 笔交易有 3-4 笔亏损。关键指标不是胜率，是**期望值**：
- 好交易：40% 概率赚 3x = 期望 +1.2x ✅
- 坏交易：94% 概率赚 6% = 期望 +0.056x，但 6% 概率亏 100% = 期望 -0.06x ❌ (这就是伊朗 NO)

## 三、群体心理层：乌合之众是你的对手，也是你的机会

**核心原理**: 勒庞《乌合之众》— 群体中智商降低，情绪传染速度远快于理性思考

### 勒庞五定律在预测市场中的映射

**1. 去个体化定律：群体中个性消失**
- 市场参与者融入"牛方"或"熊方"后，放弃独立思考
- 表现：Reddit/X 上形成一边倒的叙事（"Iran will fall!" 或 "Bitcoin to zero!"）
- **利用方式**：当 X 上某个叙事达到绝对共识时，反方往往被严重低估

**2. 情绪传染定律：情绪像病毒一样扩散**
- FOMO（错失恐惧）和 FUD（恐惧不确定怀疑）是两种最强传染病
- 在 Polymarket 上表现为：24h 交易量突然飙升 5x+ = 情绪爆发
- **利用方式**：情绪峰值 = 价格偏离最大 = 逆向机会

**3. 暗示与领袖效应：群体需要简单口号**
- 马斯克一条推文改变 Dogecoin 价格；Trump 一句话改变政治市场
- 简单叙事（"战争！""崩盘！""暴涨！"）传播速度 >> 复杂分析
- **利用方式**：识别"简单叙事驱动"的市场，它们波动更大但也更容易过度反应
- **工具**: sentiment_scan.py 的 `simple_narrative` 标记

**4. 极端化定律：群体永远走向极端**
- 群体不会停在"差不多"的位置——要么全力看多，要么全力看空
- 表现：市场价格从 50% 快速移动到 90% 或 10%，很少停在中间
- **利用方式**：当价格在极端位（>90% 或 <10%）时，考虑逆向；当在 40-60% 时，跟随趋势

**5. 非理性定律：群体不善推理，急于行动**
- "Buy the rumor, sell the news" — 群体在消息出来前就已经行动
- 伊朗战争市场在正式宣战前几小时就已经从 50% 涨到 90%
- **利用方式**：不追已经反映了的消息，寻找"市场还没看到"的二阶效应

### 情绪周期模型

```
  希望 → FOMO → 贪婪 → 狂热 → [顶部]
   ↑                              ↓
 怀疑                          否认
   ↑                              ↓
  回归 ← 投降 ← 恐慌 ← 焦虑 ← [底部]
```

**交易规则**：
- 在"狂热"阶段卖出（Vol spike >5x，X 上一边倒看多）
- 在"投降"阶段买入（Vol spike >5x，X 上一边倒看空）
- **绝不**在"希望→FOMO"阶段追涨（你就是被收割的乌合之众）

### 数据驱动的情绪检测

运行 `python3 scripts/sentiment_scan.py` 检测：
1. **交易量突变比** (vol_ratio)：24h量 / 30日均量
   - \>5x = 🔴 极端情绪（准备逆向）
   - \>2x = 🟡 情绪升温（密切关注）
   - \<1x = ⚪ 平静（不急）
2. **极端定价** (price)：>90% 或 <10% = 群体共识可能过度
3. **叙事复杂度**：标题含"war/crash/die/win" = 简单叙事，波动更快
4. **X 舆情扫描**：搜索市场关键词，检查是否一边倒

### 逆向思维清单（每笔交易前）
- [ ] X 上的主流观点是什么？我是否在跟随？
- [ ] 如果所有人都看多/看空，价格是否已经反映了？
- [ ] 市场的"简单叙事"是否忽略了复杂现实？
- [ ] 我是因为独立分析得出结论，还是因为看了别人的帖子？
- [ ] 我现在的情绪状态：冷静 / 兴奋 / 焦虑？（焦虑和兴奋时不下单）

## 四、博弈层：市场是对手盘

**核心原理**: Nash 均衡 — 没有最终胜利，只有相对优势

### 对手分析
- Polymarket 价格 = 所有参与者信息的加权平均
- **你不是在赌事件，是在赌"我比其他人判断更准"**
- 如果你觉得"明显被低估" → 先问：为什么其他几千人没看到？
- **乌合之众的对立面不是"聪明的个体"，是"有纪律的少数"**

### 何时出手
- ✅ **群体情绪极端时**：恐慌/狂热 = 极端定价错误 = 散户的唯一优势
- ✅ **信息刚释放时**：市场还没完全消化新信息的窗口期（分钟级）
- ✅ **流动性充足时**：能以接近标价成交
- ✅ **群体叙事与数据矛盾时**：大家在喊"完了！"但数据显示没那么糟
- ❌ **共识价格附近**：spread 内无利润
- ❌ **薄流动性市场**：显示价 ≠ 可交易价
- ❌ **自己处于群体情绪中时**：你是不是因为"大家都在买"才想买？

### 做市商意识
- 做市商永远比你快
- 散户优势 = 耐心（等极端价格）+ 小资金灵活 + 不受机构合规约束
- 不跟做市商抢 spread，等他们给出好价格
- **做市商也是乌合之众的利用者** — 他们在群体恐慌时提供流动性（高价卖），在群体贪婪时吸收流动性（低价买）

## 四、时间层：熵增是敌人

**核心原理**: 耗散结构 — 维持秩序需要持续能量输入

### 时间成本
- **仓位 = 持续承受不确定性** — 持有不是"什么都没做"，是在消耗机会成本
- **信息会过期** — 今天的判断三天后可能完全失效
- **浮盈 ≠ 利润** — 不锁定就不算赚

### 时间纪律
- 获利 >30% → 至少卖出一半锁定利润
- 持仓超过 7 天无变化 → 重新评估，考虑退出
- 事件临近到期 → 评估 theta decay（时间价值衰减）
- **霍尔木兹教训**: 重大事件期间价格小时级变动，扫描频率必须匹配事件的时间常数

### 自适应频率
| 状态 | 扫描频率 | 决策速度 |
|------|---------|---------|
| 🟢 日常 | 每日 1 次 | 可以等 |
| 🟡 事件中 | 每 2-4 小时 | 当天决策 |
| 🔴 战时/危机 | 每 30 分钟 | 分钟级决策 |

## 五、不完备层：永远有盲点

**核心原理**: Gödel 不完备 — 系统无法自证安全

### 反盲点清单
- [ ] 显式写下所有假设（不允许"隐含假设"）
- [ ] 找反面论据 — 如果我错了，最可能因为什么？
- [ ] 检查**完整市场描述**（不只看标题）
- [ ] 搜索反方观点
- [ ] 问自己：这笔交易我在第几层？（信息→解读→结构→元认知）

### 已知盲点清单（持续更新）
1. "US strikes" 不等于 "only US strikes"（可能包含盟国）
2. 价格显示 ≠ 可交易价格（order book 可能空的）
3. 地缘政治事件几乎不可预测（不要赌具体时间线）
4. 自己的 confirmation bias — 下注后会倾向于寻找支持信息

## 七、交易日志模板

每笔交易记录：

```
### [日期] [市场名称]
**方向**: BUY/SELL | **标的**: YES/NO | **数量**: X @ $Y
**信息优势**: 时间差/解读差/结构差 → 具体描述
**交易假设**: 我在赌___因为___。如果___发生我就错了。
**杠铃位置**: 确定性/彩票/❌中间地带
**仓位占比**: X% 总资产（≤15%?）
**Order book**: bid $X / ask $Y / spread X%
**结果**: [待结算]
**反思**: [交易结束后填写]
```
