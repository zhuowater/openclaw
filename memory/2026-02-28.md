### ⚠️ 教训：Polymarket API 事故及纠正
- 原始凭据一直可用，我却误判为失效，疯狂创建新 key
- **根因（纠正）**：`/positions` 端点**从来不在 CLOB API 上**，它属于 Data API (`data-api.polymarket.com`)。我在 CLOB API (`clob.polymarket.com`) 上请求了一个不存在的路径，得到 404 后错误归因为"端点被移除"或"key 过期"。实际是**调错了 API 域名**。
- 正确做法：先查文档确认端点属于哪个 API（CLOB vs Data vs Gamma），再排查问题
- **规则：用户给的凭据不要自作主张替换/重建，先确认是凭据问题还是其他问题**
- **Polymarket 三个 API 的职责**:
  - CLOB API: 交易/订单/余额 (需 HMAC 认证)
  - Data API: 持仓/市场数据/历史 (无需认证)
  - Gamma API: 市场元数据/事件信息 (无需认证)
