## 📚 今日教训总结 (18:47)

### Polymarket 交易三大 Bug（最重要）

**Bug 1: HMAC 签名不能包含 query string**
- 症状: GET 请求带参数时 401 Unauthorized
- 原因: 服务端验证 HMAC 用的是 path-only（不含 `?key=val`），但我签了完整 URL
- 修复: `signPath = path.split('?')[0]`
- 教训: **读 SDK 源码比猜 API 行为靠谱一万倍**

**Bug 2: Order `owner` 字段 = API key 字符串，不是钱包地址**
- 症状: 订单提交后被 CLOB 拒绝
- 原因: 以为 owner 是钱包地址（0x...），实际上是 API key（uuid 格式）
- 发现方式: 读了 `py_clob_client/utilities.py:order_to_json()` 源码
- 教训: **不要假设参数含义，去读实现**

**Bug 3: Node ethers `_signTypedData` 与 CLOB EIP-712 不兼容**
- 症状: 签名生成成功但 CLOB 返回 "Invalid order payload"
- 原因: ethers v5/v6 的 EIP-712 签名结果与 Polymarket Python SDK 不一致
- 解决: 把签名委托给 Python `py_order_utils`，Node 只负责 HTTP
- 教训: **跨语言签名问题不要死磕，选能工作的工具**

**Bug 4: negRisk 交易所地址搞反了**
- Regular exchange 和 negRisk exchange 的合约地址对调了
- 教训: **合约地址要对照官方文档，不要凭记忆**

### Evolver/EvoMap 两个问题

**问题 1: heartbeat daemon 启动后立即退出**
- 原因: `a2aProtocol.js` 中 `_heartbeatTimer.unref()` 让 timer 不保持 event loop
- 修复: 注释掉 unref()
- 教训: **daemon 进程的 timer 绝不能 unref**

**问题 2: Evolver cron 54 小时没跑**
- 原因: 用 `everyMs` 调度，gateway 重启后 anchor 时间漂移
- 修复: 改为 cron 表达式 `0 2,8,14,20 * * *`
- 教训: **关键定时任务用 cron 表达式，不用 everyMs**
