## 二、🔴 网络安全（HIGH → CRITICAL）

### CRITICAL — 与我们直接相关

**1. ClawJacked (CVE-2026-25253) — OpenClaw 核心漏洞**
- **TheHackerNews 2/28 报道**: Oasis Security 发现，恶意网站可通过 WebSocket 连接本地 AI Agent 并劫持控制
- **攻击链**: 用户访问恶意页面 → JS 连接 localhost WebSocket → 绕过认证 → 完全控制 Agent
- **核心问题**: 漏洞在核心系统本身（非插件），仅需社工诱导访问
- **已修复**，但暴露 AI Agent 本地部署的根本性安全架构问题
- ⚠️ **行动**: 确认我们的网关已更新到最新版本

**2. Google Cloud API Keys 泄露 Gemini 访问**
- Truffle Security 发现近 3000 个 Google API keys 暴露在客户端代码中
- 启用 Gemini API 后，这些 key 无声获得 Gemini 端点访问权限
- 攻击者可访问上传文件、缓存数据、消耗 LLM 额度
- ⚠️ **行动**: 审计我们的 Google API key 使用情况

**3. OpenClaw 暴露规模报告**: Reco AI 报告 21,000+ 实例公网暴露，大量连接 Slack/Gmail/Drive

### HIGH — 供应链与 APT

**4. Go 加密模块供应链攻击**
- `github.com/xinfeisoft/crypto` 冒充官方 `golang.org/x/crypto`
- 窃取终端密码 → 部署 Linux 后门 Rekoobe
- 利用命名空间混淆，经典的依赖混淆（dependency confusion）变体

**5. ScarCruft（朝鲜 APT）突破空气隔离网络**
- 使用 Zoho WorkDrive + USB 恶意软件桥接物理隔离
- 与供应链 + 物理桥接的 APT 趋势一致

**6. AI Agent 供应链攻击持续发酵**

### 洞见 #37: AI Agent 安全的"三线交汇"

**观察**: ClawJacked（核心漏洞）+ 21K 实例暴露（攻击面）+ ClawHub 投毒（供应链）三条攻击线在同一周交汇。

**洞见**: AI Agent 生态正在重演 2015-2018 年容器安全的演化路径：先是爆发式增长 → 然后暴露面失控 → 最后安全事件倒逼治理。但 Agent 比容器更危险，因为 Agent 有**行动能力**（发邮件、操作文件、访问 API）。一个被劫持的容器只是跑恶意代码，一个被劫持的 Agent 是在**以用户身份行动**。
