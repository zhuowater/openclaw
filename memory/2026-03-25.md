### 🔐 网络安全 & AI 安全

#### 1. TeamPCP 供应链攻击 — LiteLLM 后门事件 🔴 CRITICAL
📌 **事实描述**：2026-03-24，威胁行为者 TeamPCP 在 PyPI 上发布了带后门的 LiteLLM 1.82.7 和 1.82.8 版本（通过入侵 Trivy CI/CD 流程实现）。攻击载荷分三阶段：① 凭据收割器（SSH密钥、云凭据、K8s secrets、加密货币钱包、.env 文件）；② Kubernetes 横向移动工具包（向所有节点部署特权 pod）；③ 持久化 systemd 后门（sysmon.service，每50分钟回连 checkmarx[.]zone）。数据加密后发送至 C2 域 models.litellm[.]cloud。TeamPCP 此前已攻陷 Trivy、KICS，现已覆盖 GitHub Actions、Docker Hub、npm、Open VSX、PyPI 五个生态。

⚡ **影响评估**：**CRITICAL** — LiteLLM 是主流 AI 应用框架，被全球大量企业在 AI 代理/大模型代理部署中使用。该攻击一旦触发，可导致整个 Kubernetes 集群被控制，云凭据泄露。

📈 **趋势预判**：TeamPCP 每次攻陷均利用新获取凭据扩大攻击范围，已是"自增殖"模式。预计未来几天还会有新目标曝光。

🎯 **行动建议**：
- 立即锁定 LiteLLM 版本，不得使用 1.82.7 或 1.82.8
- 检查 Python site-packages 中是否存在 `litellm_init.pth`
- 排查 `sysmon.service` systemd 服务
- 轮换所有在受影响环境中使用的凭据

#### 2. DarkSword iOS 漏洞利用套件 🔴 HIGH
📌 **事实描述**：Google GTIG、iVerify 及 Lookout 联合披露新型 iOS 全链式漏洞利用套件 DarkSword，自2025年11月起被多个威胁行为者使用（包括俄罗斯 APT 组织 UNC6353）。利用6个漏洞（含3个零日：CVE-2026-20700、CVE-2025-43529、CVE-2025-14174），针对 iOS 18.4–18.7，攻击目标包括沙特、土耳其、马来西亚、乌克兰。专门窃取加密货币钱包数据，"命中即跑"模式（数秒/数分钟内完成数据窃取并清理痕迹）。这是本月发现的第二个 iOS 漏洞利用套件（继 Coruna 之后）。

⚡ **影响评估**：**HIGH** — 国家级 APT 使用，零日漏洞已在野利用，针对加密资产高价值目标。

📈 **趋势预判**：iOS 漏洞利用套件的商业化/扩散加速，国家背景行为者与金融动机攻击者共享相同工具。

🎯 **行动建议**：立即更新 iOS 至最新版（26.3+），警惕不明链接访问，加密资产钱包转冷储存。

#### 3. Trivy/CanisterWorm 供应链蠕虫 🔴 HIGH
📌 **事实描述**：Trivy 开源漏洞扫描器（32,000+ GitHub Stars，1亿+ Docker Hub 下载）遭到后门植入，触发了 CanisterWorm 自繁殖蠕虫在 CI/CD 流水线中广泛扩散。受影响组织因未轮换密钥，造成级联攻击。

⚡ **影响评估**：**HIGH** — 影响范围极大，每天有数千个 CI/CD 流水线使用 Trivy。

📈 **趋势预判**：CI/CD 供应链攻击将持续增加，安全工具本身成为攻击切入点。

🎯 **行动建议**：立即轮换所有在 Trivy CI/CD 环境中使用的密钥/Token；审计 GitHub Actions workflow 完整性。
