## 技术发现：Clawdbot 浏览器截图限制

### 问题诊断
用户遇到浏览器 fullPage 截图被压缩到 450px 左右的问题。经过深入调查源码，发现：

**根本原因：**
- Clawdbot 的 `/usr/lib/node_modules/openclaw-cn/dist/browser/screenshot.js` 中的 `normalizeBrowserScreenshot` 函数有强制压缩逻辑
- 默认限制截图文件大小为 5MB (`DEFAULT_BROWSER_SCREENSHOT_MAX_BYTES`)
- 如果原始截图超过 5MB，会不断降低质量和尺寸，直到符合限制
- fullPage 截图因为内容太长，触发了这个压缩逻辑，被强制缩小

**排除的可能性：**
1. ✗ Chrome 启动参数没有设置窗口大小 (已确认 chrome.js 中确实没有 `--window-size`)
2. ✗ resize 操作不生效 (通过 `page.evaluate()` 验证窗口确实是 1920x1080)
3. ✓ **确认是压缩策略问题**

**关键代码位置：**
- `/usr/lib/node_modules/openclaw-cn/dist/browser/screenshot.js` - 截图压缩逻辑
- `/usr/lib/node_modules/openclaw-cn/dist/browser/chrome.js` - Chrome 启动参数

**可能的解决方案：**
1. 修改源码中的 `DEFAULT_BROWSER_SCREENSHOT_MAX_BYTES` 常量（需要重新编译）
2. 不使用 fullPage，分段截图
3. 使用外部工具绕过 Clawdbot 的截图功能

### 调查方法
- 阅读源码文件
- 使用 `page.evaluate()` 验证实际窗口尺寸
- 查阅 Playwright 官方文档对比预期行为

### 经验教训
遇到行为异常时，深入源码比反复尝试参数更高效。这次通过阅读 `screenshot.js` 和 `chrome.js` 直接定位到了压缩逻辑。
