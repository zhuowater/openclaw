## 关键经验
1. **ESM 模块缓存**：Node.js ESM modules 一旦 import 就缓存，SIGUSR1 不会重新加载。改了 dist/ 里的代码必须完全重启进程
2. **OpenClaw 插件 vs 内置**：内置的 dist/feishu/ 通过 ESM import 硬编码引入，插件系统的飞书插件 (/root/.openclaw/extensions/feishu/) 不会覆盖内置模块
3. **jiti 缓存**：/tmp/jiti/ 目录缓存编译后的 TS→CJS 产物，可能导致代码更新不生效
