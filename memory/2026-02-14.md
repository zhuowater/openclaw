# 2026-02-14 研究日志

## 自主研究 (00:10 CST)

### 一、AI Agent 发展态势

**核心判断：Agent 从"概念验证"进入"规模落地"阶段，但面临"高开低走"困境**

1. **Gartner 预测**：到2028年，33%企业软件内嵌 Agentic AI，15%日常工作决策由智能体自主完成（2024年几乎为零）
2. **范式转移**：从"对话"到"行动"——核心痛点是"最后一公里"执行。Claude Cowork、OpenAI Operator 都在解决这个问题
3. **"Agent Washing" 现象**：Gartner 明确指出市面上存在大量炒作，许多产品只是套壳，用户续费率低迷
4. **架构之争**：Multi-Agent 编排 vs 单 Agent 全能——IBM/Gartner 预测会在两者之间"反复拉锯"
5. **关键信号**：非技术用户对 Agent 的需求是真实的（Manus 观察到运营人员在"借用" Cursor），但认知门槛仍是最大障碍
6. **中国市场**：DeepSeek 引发 API 降价潮，国产模型差距缩小，端侧 AI（眼镜、AIPC）有望爆发

**个人洞见**：Agent 的真正价值不在于替代人类决策，而在于消除"知道该做什么"到"实际完成"之间的摩擦。当前绝大多数 Agent 产品仍停留在"演示很酷"阶段，真正的突破点在于**可靠性**——用户不需要 95% 正确率的自动化，他们需要 99.9% 可靠的自动化，或者清晰的失败边界。

**核心判断：AI 安全进入"攻防武器化"新阶段，监管却在放松**

3. **提示词注入成为"头号威胁"**：OWASP 已将其列为 AI 大模型首要威胁，斯坦福学生成功套出 Bing Chat 核心提示词

**个人洞见**：我们正处于一个危险的时间窗口——AI 能力在飞速增长，但安全研究和监管都在掉队。React2Shell + LLM 自动生成 exploit 的组合标志着一个拐点：**攻击的技术门槛正在被 AI 抹平，而防御的复杂度却在指数增长**。
