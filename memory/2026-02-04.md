### 22:27 - 截图清晰度问题
- 用户反馈图片模糊
- 根因分析：
  1. 浏览器默认窗口宽度小（~341px）
  2. 全页截图被压缩
  3. 原始截图只有 341x2000 分辨率
- 首屏截图质量稍好，但仍不理想
- 发现飞书可能对上传图片有压缩
- **配置限制**：Clawdbot 当前 browser 配置不支持自定义 Chrome 启动参数（args）
- **workaround方案**：
  1. 每次截图前先调整窗口: `browser action=act request='{"kind": "resize", "width": 1920, "height": 1080}'`
  2. 以文件形式发送避免压缩（但不解决原始分辨率问题）
- **待上游支持**：需要 Clawdbot 添加 browser.args 配置支持

## 技术发现

### 浏览器截图质量
- 当前 browser 工具不支持动态设置窗口大小
- 需要通过配置文件 `channels.feishu` 或 `browser` 添加启动参数：`--window-size=1920,1080`
- fullPage 截图在小窗口下会严重降低分辨率

### 飞书图片上传
- 飞书 API 可能自动压缩图片
- 可选方案：作为文件（filePath）而非图片发送，保留原始质量
