## 飞书语音消息适配调试

### 重大突破：type="file" 是关键
- **问题**: 飞书语音消息一直无法被正确识别和下载
- **尝试过的方案**:
  - `type="audio"` - 失败，导致错误 "Unknown media type"
  - 检查 feishu channel 插件代码，发现混乱的类型判断逻辑
- **最终解决方案**: 
  - 将语音消息的 type 从 "audio" 改为 **"file"**
  - 文件类型: `audio/ogg; codecs=opus`
  - 成功下载路径示例: `/root/.openclaw/media/inbound/efcec4dc-1ddb-4f38-98ac-f499794387d0`

### 代码修改位置
- 文件: `feishu/channel.ts` (第 1066 行附近)
- 原代码: `type: "audio"`
- 修改为: `type: "file"`
- 对应的 mime type: `message_type === "audio"` 时设置为 `audio/ogg; codecs=opus`
