## 飞书图片发送问题修复 ✅

### 问题
- `message` 工具发送图片到飞书失败（400 错误："Error when parsing request"）
- 原因：Node.js form-data 库与飞书 API 不兼容

### 解决方案
创建 `/root/openclaw/skills/feishu-media/` 技能：

**send-image.js**（主脚本）
- 使用官方 @larksuiteoapi/node-sdk
- 两步流程：上传图片获取 image_key → 发送消息
- 自动识别 open_id 和 chat_id
- 支持可选文字说明

**使用方法**
```bash
node /root/openclaw/skills/feishu-media/send-image.js <图片路径> <接收者ID> [说明文字]

# 或使用环境变量
export FEISHU_TARGET_ID=ou_xxx
node /root/openclaw/skills/feishu-media/send-image.js <图片路径>
```

**作为模块**
```javascript
import { sendImageToFeishu } from '/root/openclaw/skills/feishu-media/send-image.js';
await sendImageToFeishu(imagePath, targetId, caption);
```

### 教训
- 遇到第三方 API 问题时，先用 curl 验证是否是代码问题
- 官方 SDK 比自己实现 HTTP 请求更可靠
- form-data 在不同环境下行为不一致，需要小心处理流和 Buffer
