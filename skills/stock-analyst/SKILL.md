**首先执行：市场体制识别**（决定后续所有指标的解读方向）

```python
import tushare as ts, numpy as np, pandas as pd

pro = ts.pro_api()

def detect_regime(index_code='000300.SH', lookback=252):
    """
    三体制识别：牛市 / 熊市 / 震荡
    基于沪深300（或科创50等相关指数）200日均线斜率与价格位置
    """
    df = pro.index_daily(ts_code=index_code,
                         start_date=pd.Timestamp.today().strftime('%Y%m%d'),
                         end_date=pd.Timestamp.today().strftime('%Y%m%d'))
    # 取近1年+数据
    df2 = pro.pro_bar(ts_code=index_code, asset='I',
                      start_date=(pd.Timestamp.today()-pd.DateOffset(days=lookback+60)).strftime('%Y%m%d'))
    df2 = df2.sort_values('trade_date')
    df2['ma200'] = df2['close'].rolling(200).mean()
    df2['ma200_slope'] = df2['ma200'].diff(20)  # 20日斜率
    last = df2.iloc[-1]
    price_above_ma200 = last['close'] > last['ma200']
    ma_rising = last['ma200_slope'] > 0

    if price_above_ma200 and ma_rising:
        return 'BULL'    # RSI高位=追涨，动量有效
    elif not price_above_ma200 and not ma_rising:
        return 'BEAR'    # RSI高位=减仓，动量失效
    else:
        return 'RANGE'   # RSI极值=反向操作

# 体制决定指标含义：
# BULL:  RSI=70 → 继续持有；MACD金叉 → 加仓
# BEAR:  RSI=70 → 减仓；    MACD金叉 → 反弹卖出
# RANGE: RSI=70 → 做空；    MACD金叉 → 短线操作
```

**期权隐含波动率（IV）精确计算：**
```python
def bs_price(S, K, T, r, sigma, opt_type):
    if T <= 0: return max(0, (S-K) if opt_type=='C' else (K-S))
    d1 = (np.log(S/K) + (r + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
    d2 = d1 - sigma*np.sqrt(T)
    if opt_type == 'C': return S*norm.cdf(d1) - K*np.exp(-r*T)*norm.cdf(d2)
    else: return K*np.exp(-r*T)*norm.cdf(-d2) - S*norm.cdf(-d1)

def calc_iv(mkt_price, S, K, T, r, opt_type):
    if mkt_price <= 0 or T <= 0: return np.nan
    try:
        f = lambda s: bs_price(S, K, T, r, s, opt_type) - mkt_price
        if f(0.001) * f(20.0) > 0: return np.nan
        return brentq(f, 0.001, 20.0, xtol=1e-6)
    except: return np.nan

# 无个股期权时使用同板块ETF期权代理：
# 科创板 → OP588000.SH；沪深300 → OP510300.SH
# ETF价格必须用 fund_daily，不是 pro_bar
fd = pro.fund_daily(ts_code='588000.SH', start_date='20260310', end_date='20260317')
S = float(fd.sort_values('trade_date')['close'].iloc[-1])
```

**Kelly 仓位计算：**
```python
def kelly(win_prob, win_ret, loss_ret):
    """
    win_prob: 盈利概率；win_ret: 盈利幅度（如0.30）；loss_ret: 亏损幅度（正数，如0.15）
    返回 (full_kelly, half_kelly)
    实践中使用 half_kelly 控制回撤
    """
    b = win_ret / loss_ret
    k = (b * win_prob - (1 - win_prob)) / b
    return max(0, k), max(0, k / 2)
```

**估值反直觉检验：**
- 分析师共识目标价 vs 当前股价：若目标价**低于**当前价，往往是分析师集体追随下跌，可能是逆向买入信号
- 低 P/E ≠ 便宜：检验是否为价值陷阱（ROE下滑 + 行业天花板）
- 高 P/E ≠ 贵：成长股用 PEG 和 DCF 终值权重判断

**DCF均值回归修正（必须执行）**：
```
传统DCF：第1-5年用近3年增速，第6年直接跳到永续增长率
均值回归DCF：
  第1-2年：近3年CAGR
  第3-4年：(近3年CAGR + 行业中位增速) / 2   ← 回归过渡
  第5年：行业中位增速 × 1.2（龙头溢价）
  永续期：GDP增速 + 通胀
```
> 不做均值回归修正 = 默认护城河永远不会被侵蚀，这在统计上99%的时候是错的。

**应计盈利质量评分（Sloan因子）**：
- 应计比率 = (净利润 - 经营现金流) / 平均总资产
- < 0%：✅ 现金超越利润，极高质量
- 0-5%：正常
- 5-10%：注意
- > 10%：⚠️ 盈利质量差，Sloan(1996)研究此类股票未来12月跑输8-10%

**低波动率溢价（反CAPM）**：
- Beta < 0.7 的股票在A股长期系统性跑赢 Beta > 1.3 的股票（Baker et al. 2011，A股验证更显著）
- 原因：公募基金相对收益考核 → 过度追买高Beta → 高Beta系统性高估
- **低Beta不是弱点，是长期超额收益的来源**，不应在报告中以"防御性"轻描淡写

## 输出质量底线

**必须模块（缺失则报告无效）**：
- 负一号模块（隐形风险解剖台）**必须完成**，风险点需汇总
- 零号模块（空方论点）**必须完成**，不可省略
- 行业/主题/成长股/科技股必须完成“产业链卡点与证据阶梯”：先排层级再排公司，至少给出一个热门但降级的方向
- 有明确的投资评级和目标价
- 叙事对称性检验：必须写出多头叙事和空头叙事，并指出哪个更容易被证伪

**数据质量标准**：
- 定量数据标注来源（Tushare接口名 / 网络搜索）
- VWAP 必须来自 Tushare 分钟数据累积计算
- IV 必须来自 Black-Scholes 反解；无个股期权时注明代理标的
- HV 提供至少 HV20 和 HV60 两个周期，与 IV 对比
- DCF必须使用均值回归修正，不得将当前增速外推超过3年

**反直觉信号必须覆盖**：
- 52周高点距离（距高点<3%=突破候选，非阻力）
- 应计比率（盈利质量，Sloan因子）
- 分析师覆盖密度（>50家=alpha归零预警）
- 融资余额/流通市值（分档非线性风险）
- 连续超预期年数（>5年=首次miss永久伤害风险）

**分析哲学**：
- 所有技术指标须注明当前市场体制，体制不同则解读不同
- Kelly 仓位必须基于明确的胜率和赔率假设，不接受"适量"等模糊表述
- 压力测试覆盖至少3个极端情景
- 风险因素附概率、影响幅度和对冲成本估算
- 有清晰的止损位（参考 VWAP）和止盈位（参考 Kelly 仓位）

> **最高原则**：数据不足时**宁缺毋编**，客观性高于完整性。
> **第二原则**：分析的目的是证伪，不是证明。能被证伪的分析才是有价值的分析。
> **第三原则**：所有"显而易见"的结论都已被定价。真正的alpha来自市场共识的错误，而不是正确。
