# 量化/AI策略验证清单（YouTube量化高热内容消化版）

> 用途：当报告引用 AI/量化/回测/因子/Trading Bot/Claude Code 类视频或方法时，必须把“想法”降落成可复现实验。没有通过本清单，不得把视频里的策略当买卖信号。

## 1. 策略假设卡（先写，后回测）

- 预测对象：绝对收益、超额收益、突破概率、回撤风险，还是波动率？
- 标的池：是否包含历史退市、ST、新股、停牌；若只用当前成分股，必须标注幸存者偏差。
- 信号时间戳：财报、公告、资金流、舆情、YouTube/X情绪在交易当时是否已经可见？
- 调仓规则：信号产生后 T+1、next open、next VWAP 还是收盘价成交？
- 入场/出场/止损/止盈/再平衡/仓位上限是否完整？
- 失效条件：什么数据出现说明策略逻辑错了？

## 2. 回测偏差审计

- 无未来函数：所有信号必须 `shift(1)` 后交易；财务数据按披露日 lag。
- 无偷看参数：参数只在训练窗选择，测试窗不可回填优化。
- 无幸存者偏差：股票池包含历史变化；做不到则降低置信度。
- 复权口径一致：交易价格、收益、分红、停复牌处理一致。
- A股执行约束：T+1、涨跌停、一字板、停牌、最小100股、印花税。
- 容量约束：单笔成交额不得超过当日成交额合理比例；高换手策略做冲击成本。

## 3. Walk-forward 与过拟合检查

- 时间切分：训练/验证/测试按时间顺序，不可随机切分。
- Walk-forward：滚动训练窗口选择参数，只在下一测试窗交易。
- 参数稳定性：优秀参数应是一片平台，不是孤立尖峰。
- 子样本：跨年份、牛熊震荡、行业、大小盘分组仍有效吗？
- 随机基线：随机信号、置换收益、Bootstrap 后是否仍显著？
- 多重检验：披露测试过多少因子/参数组合，防止 p-hacking。

## 4. 因子研究标准输出

- 因子定义公式 + 经济解释。
- IC/Rank IC：均值、标准差、t值、胜率、衰减半衰期。
- 分位数组合：收益单调性、long-short收益、最大回撤。
- 中性化：行业/市值/流动性中性后是否仍有效。
- 换手与成本后收益：高换手因子必须扣成本。
- 因子相关性：避免把已有风格/Beta暴露误当Alpha。

## 5. AI/Claude Code 量化护栏

- AI只生成假设、代码、测试、报告；不得直接生成“买入/卖出事实”。
- AI写的策略必须配单元测试：信号滞后、成本扣除、数据对齐、无NaN作弊。
- 每次改参数/逻辑记录 experiment_id；限制迭代次数。
- 保留最终盲测集；看过盲测结果后不得继续调参。
- 自动交易必须先 paper trading，并有风控熔断、订单日志、异常处理。

## 6. 报告评级规则

- 只看视频/论文想法，未回测：`想法线索`，不能进投资结论。
- 样本内有效，未样本外：`低置信度候选`。
- 样本外有效但未扣成本：`中低置信度`。
- Walk-forward + 成本后 + 子样本稳健：可进入 `量化证据`。
- A股执行约束无法成交/容量不足：即使回测好看，也降级为不可交易。
