# Serenity式产业链卡点研究增强

本参考吸收 `muxuuu/serenity-skill` 的核心方法论，用于把股票分析从“券商式单票报告”升级为“产业链真实约束 + 证据链 + 市场误解”的研究。

## 一句话原则

先排产业链层级，再排公司；先找真实扩产约束，再看谁最接近约束；先验证证据强度，再谈估值与交易。

默认推理链：

```text
市场叙事 → 系统变化 → 被拉紧的物理/经济约束 → 产业链层级 → 稀缺卡点 → 上市公司 → 证据 → 市场可能没看清的地方 → 证伪条件
```

## 适用场景

- 行业/主题研究：AI算力、半导体、CPO、液冷、机器人、电力设备、新材料、军工、生物制造等。
- 单票分析：判断公司到底卡住什么环节，还是只是“蹭主题”。
- 多候选对比：先比较层级稀缺性，再比较公司质量。
- 用户问“哪个最值得研究/买/低吸”：输出研究优先级与交易区间，不直接替用户下单。

## 工作流

### 1. 把故事翻译成系统变化

回答：
- 需求波来自哪里？
- 旧架构哪里被拉紧？
- 最关键约束是：功耗、带宽、延迟、散热、良率、纯度、可靠性、认证周期、产能、牌照/电网接入，还是客户验证？

例：
- AI集群 → 带宽/功耗压力 → 光互连、交换、封装升级 → 激光器/DSP/测试/封装/PCB/液冷卡点。
- 人形机器人 → 执行器和传感密度提高 → 减速器、电机、编码器、触觉传感、制造良率和客户认证。

### 2. 先排产业链层级

使用这张层级清单，不要一上来列热门股票：

1. 下游需求与资本开支来源
2. 系统集成/OEM
3. 模组与子系统
4. 芯片、器件、关键零部件
5. 工艺、组装、封装、测试
6. 设备、量测、检测
7. 材料、耗材、特殊输入
8. 物理基础设施：电力、散热、厂房、网络、物流

对主题扫描，必须先输出“层级排序”。至少解释一个热门但排序靠后的层级为什么降级。

### 3. 识别卡点

卡点强度来自多个信号叠加：

| 信号 | 含义 |
|---|---|
| 供应商少 | 议价权更可能在供给侧 |
| 认证周期长 | 客户切换成本高，替代慢 |
| 扩产难 | 设备/工艺/牌照/纯度/Know-how限制供给 |
| 客户预付款/长单/产能锁定 | 需求急迫且愿意承担供给风险 |
| 毛利率/订单/合同负债验证 | 稀缺性进入财务而非停留在故事 |
| 市场仍按旧业务分类 | 可能存在重估差 |

### 4. 建候选池再排序

- 宽主题扫描：候选池尽量 ≥20家公司，覆盖龙头、上游设备、材料、检测、封装、基础设施、明显热门但可能降级的公司。
- 最终Top 3-7必须回答：`卡住什么 / 产业链位置 / 排序原因 / 证据 / 主要风险`。
- 单票分析也要给公司分型：控制卡点、供应卡点、受益但控制力弱、只有题材故事。

## 证据阶梯

### 强证据

- 年报/半年报/季报、临时公告、交易所问询函/监管函；
- SEC/HKEX/SSE/SZSE/BSE/MOPS/TDnet/DART等交易所或监管文件；
- 官方订单、合同、中标、产能锁定、预付款、客户认证；
- 环评/能评、项目备案、土地/设备/产线进度；
- 专利、标准、技术论文、认证记录；
- 业绩会纪要、投资者演示、官方IR材料。

### 中证据

- 可信财经媒体、产业媒体、行业协会数据；
- 公司官网/产品页；
- 假设透明的卖方/专家研究；
- 上下游上市公司披露的交叉验证。

### 弱证据

- KOL、雪球/股吧/X/YouTube、论坛、截图、未注明来源的渠道消息；
- 只有价格异动/放量而没有基本面证据。

规则：弱证据只能做线索，不得支撑最高优先级或买卖结论；每个Top候选至少需要1条强/中证据支持业务位置，另1条证据支持需求、产能、客户、财务或估值。

## A股特别核查源

- 年报、半年报、季报、临时公告；
- 交易所问询函、互动易、上证e互动；
- 招投标、中标公告、客户认证/验厂；
- 环评/能评、地方项目备案、土地/产线/设备进度；
- 专利、标准、行业协会；
- 应收、存货、合同负债、经营现金流、毛利率、在建工程转固；
- 关联交易、资产注入、定增、可转债、股权质押；
- 上下游披露、海关/进出口线索。

## Serenity卡点评分维度（0-5分）

正向：需求拐点、架构耦合度、卡点严重度、供应商集中度、扩产难度、证据质量、估值错位、催化时点。

扣分：融资摊薄、治理、地缘政治、流动性、炒作拥挤、会计质量、周期性、替代技术风险。

## 常见错误

- 错误：先列股票，再给每只股票找理由。正确：先排层级，再映射公司。
- 错误：把“AI芯片/EDA/IP/设备/材料/封测”混成一个桶。正确：按经济属性和证据路径拆层。
- 错误：把社媒热度当证据。正确：社媒只做线索和情绪温度计。
- 错误：只说“受益于国产替代”。正确：说明到底卡住什么、客户为什么绕不开、财务何时验证。
- 错误：只输出买入评级。正确：给研究优先级、证伪条件、下一步验证路径和交易区间。
