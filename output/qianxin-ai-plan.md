# 奇安信人工智能公司 — 面向未来的战略方向与商业计划

*基于 2026年3月3日内部规划会议纪要，结合 AI 安全行业前沿趋势*

---

## 一、核心判断：我们站在哪里

### 1.1 会议共识（已确定）

齐总在会议中明确了几个关键判断：
- AI 是第四次工业革命的核心技术，未来 100 年的变革基础
- 智能体是 AI 时代的"网站"，是核心应用形态
- 安全的护城河被填平，需要用 AI 重构
- "攻防驱动 AI" 是公司宗旨
- 500 人 all in，收入目标 4-5 亿，行业第一

### 1.2 补充判断（需要关注的趋势）

**趋势一：AI Agent 正在从"工具"变成"基础设施"**

2026 年的智能体不再是"聊天机器人"。它们已经在：
- 自主操作浏览器、API、数据库
- 7×24 运行，无需人类监督
- 形成多 Agent 协作网络（Agent-to-Agent）
- 访问企业核心系统（ERP、CRM、代码库、生产环境）

**这意味着：每个 Agent 都是一个潜在的攻击面。** Agent 安全不是"锦上添花"，而是 AI 落地的前提条件。

**趋势二：AI 供应链安全是下一个万亿级问题**

就像软件供应链攻击（SolarWinds、Log4j）改变了安全行业，AI 供应链攻击正在成为现实：
- **模型投毒**：在训练数据中植入后门
- **Agent 投毒**：恶意 Skill/Plugin 通过 Agent 商店分发（已有真实案例：ClawHub 1184 个恶意 Skills）
- **提示词注入**：通过输入操控 Agent 行为
- **数据外泄**：军工工程师上传设计文档到境外大模型（会议中提到的真实案例）

**趋势三：监管红利正在到来**

网信办、工信部正在加速 AI 安全标准制定。能够提供合规解决方案的公司将获得巨大的政策红利。

## 二、战略方向：超越"AI+安全"

### 2.1 升级为"三层五线"战略

在齐总 "Security for AI + AI for Security" 双轮框架基础上升级：

```
┌─────────────────────────────────────────────────┐
│  第三层：AI 治理与合规 (Governance)               │
│  标准制定 · 风险评估 · 审计认证                    │
├─────────────────────────────────────────────────┤
│  第二层：AI 安全产品 (Products)                   │
│  Agent安全 · 模型安全 · 数据安全 · 供应链安全       │
├─────────────────────────────────────────────────┤
│  第一层：AI 安全能力 (Capabilities)               │
│  攻防研究 · 漏洞挖掘 · 威胁情报 · 红队             │
└─────────────────────────────────────────────────┘
```

- **第一层**（攻防能力）= 齐总说的"攻防驱动 AI"，是根基
- **第二层**（安全产品）= 收入主力，直接卖给企业
- **第三层**（治理合规）= 高毛利、高壁垒，卡位监管红利

### 2.2 五条产品线

#### 产品线 1：Agent 安全平台 AgentShield ⭐ 核心产品

对应会议决策：智能体商店 + 智能体行为监管

升级方向——不只是"监管"，而是提供完整的 Agent 安全生命周期管理：

| 阶段 | 能力 | 产品形态 |
|------|------|----------|
| 开发期 | Agent 代码审计、Skill 漏洞扫描 | SDK + CI/CD 插件 |
| 部署期 | Agent 商店安全评估、供应链验证 | SaaS 平台 |
| 运行期 | 实时行为监控、异常检测、权限控制 | 网关/Sidecar |
| 运维期 | 审计日志、合规报告、事件响应 | Dashboard |

**为什么是核心**：每个企业部署 Agent，第一个问题就是"我怎么确保它不会搞砸？"。这是刚需，而且是按 Agent 数量付费的 SaaS 模型——随着企业 Agent 数量爆发增长，收入自然增长。

**定价模型**：按 Agent 数量 + 调用量阶梯定价。每个 Agent 每月 ¥200-2000（视企业规模和安全等级）。

#### 产品线 2：大模型安全评估 ModelGuard

建议**不自建通用大模型**（烧钱太多，竞争红海），而是做**模型安全评估和加固**：
- **红队即服务**（Red Team as a Service）：对企业使用的大模型做对抗测试
- **模型安全护栏**（Guardrails）：防止越狱、有害输出、数据泄露
- **安全基线检测**：自动化评估模型是否符合国标/行标

市场空间：每个部署大模型的企业都需要，但自己做不了（缺攻防能力）。奇安信的攻防团队是天然优势。

#### 产品线 3：AI 数据安全 DataVault

对应会议案例：军工工程师上传 MD 文件到境外大模型

- **DLP for AI**：监控和拦截敏感数据流向 AI 系统
- **隐私计算网关**：让数据"可用不可见"，安全使用大模型
- **数据分级标注**：自动识别哪些数据可以给 AI，哪些不行

这是**合规强驱动的市场**——数据安全法 + AI 监管 = 企业必须买单。

#### 产品线 4：AI 赋能安全运营 SecOps AI

对应会议提到的 "AI SOC、代码卫士和威胁情报"：
- **AI SOC**：智能安全运营中心，自动分析告警、编排响应
- **AI 代码审计**：比 OpenAI Codex Security 更懂安全，结合奇安信漏洞库
- **AI 威胁情报**：自动化情报收集、分析、预警
- **AI 渗透测试**：自动化漏洞挖掘和利用验证

这条线的逻辑：把奇安信现有安全产品 AI 化，不是全新市场，而是存量升级。

#### 产品线 5：AI 安全合规咨询 TrustAI

- AI 系统安全评估认证
- AI 治理框架咨询
- AI 安全标准参与制定（工信部、网信办、TC260）
- 行业安全白皮书（金融、医疗、军工、政府）

高毛利业务，利用奇安信的行业影响力和政府关系。

## 四、核心竞争力构建

### 4.1 攻防能力最强（根基）

- 成立 **AI 红队实验室**（AI Red Lab），专注 AI 系统攻防研究
- 每季度发布 AI 安全研究报告，建立行业话语权
- 参加 DEF CON AI Village、NIST AI Safety 等国际竞赛
- **建立中国最大的 AI 漏洞库**（AI CVE Database）

### 4.2 安全体系最全（产品）

- 5 条产品线覆盖 AI 安全全生命周期
- 统一的安全管理平台（Single Pane of Glass）
- 开放 API，与客户现有安全体系集成

### 4.3 AI 基础能力最强（技术）

**不做通用大模型，做安全垂直大模型（Security-LLM）**：
- 通用大模型：百亿级投入，DeepSeek/Kimi/Step 已经在前面
- 安全大模型：千万级投入，用奇安信独有的攻防数据训练
- 只需在"漏洞挖掘、恶意代码分析、威胁研判"等场景超越通用模型
- **这是别人有钱也做不了的——因为没有数据**

### 4.4 开源战略（关键杠杆）

会议提到张勇的智能体框架内部开源。建议更进一步——**对外开源 Agent 安全工具**：
- Agent 安全扫描器（类似 OWASP ZAP for Agent）
- 提示词注入检测库
- Agent 行为审计日志格式标准

为什么：
- 开源是最好的获客渠道（DeepSeek 证明了这一点）
- 成为事实标准 → 商业版自然有人买
- 吸引安全社区贡献者 → 降低研发成本

## 五、关键风险与应对

### 风险 1：大厂降维打击

阿里云、华为云、腾讯云自带安全能力，可能把 AI 安全做成云服务的标配。

**应对**：专注"纯安全"视角。云厂商的安全是"够用就行"，安全公司的安全是"深度对抗"。政府/军工/金融客户不会信任云厂商做安全。

### 风险 2：技术迭代太快

AI 技术 6 个月一代，产品可能还没上市就过时。

**应对**：产品架构做成"平台+插件"，核心平台稳定，安全策略可热更新；保持 30% 研发人员做前瞻性研究。

### 风险 3：人才争夺

AI + 安全的复合人才极度稀缺。

**应对**：内部培养为主（500 人中选 50 人重点培养），与高校合作联合实验室，开源社区吸引外部贡献者，**给年轻人真正的决策权和上升空间**。

### 风险 4：500 人团队管理

短期内组建 500 人独立公司，管理挑战巨大。

**应对**：第一个月不急着填满 500 人，先 200 人精锐团队跑通模式；用 Agent 替代部分重复性工作（吃自己的狗粮）；扁平化管理，避免大公司病。

## 七、额外建议

### 7.1 不要只做中国市场

AI 安全是全球性需求。中国公司在安全领域有独特优势（攻防实战经验全球领先）。建议从年度 2 开始布局国际市场，东南亚和中东是切入点。

### 7.2 "攻防驱动 AI" 需要可感知的故事

- 每季度发布一次 AI 系统重大漏洞（负责任披露）
- 在 DEF CON/Black Hat 发表研究
- 让行业记住 **"AI 安全 = 奇安信"**

### 7.3 真正的护城河 = 数据飞轮

旧护城河（代码和客户关系）确实在被填平。新护城河不只是"技术最强"：

```
客户使用产品 → 产生安全数据 → 训练更好的安全模型 
→ 产品更准确 → 更多客户使用 → 更多数据...
```

这个飞轮一旦转起来，后来者几乎无法追赶。AgentShield 的每次告警、每次审计、每次攻防对抗，都在喂养 Security-LLM。

### 7.4 关于自建大模型

齐总说"从底层自建模型"。建议：**不做通用大模型，做安全垂直大模型**。
- 通用大模型：百亿级投入，DeepSeek/Kimi/Step 已经在前面
- 安全大模型：千万级投入，用奇安信独有的攻防数据训练
- 只需在安全场景超越通用模型
- **这是别人有钱也做不了的——因为没有数据**
